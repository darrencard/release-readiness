# Examples

Every figure here is illustrative. Acme is an invented company: invoicing software for trades businesses, Series C, about 400 people, 12 squads, with an AI assistant that drafts quotes and chases invoices. The people named are invented too.

- `acme-ready/`: Quote Assistant 2.4. Every criterion is met, so the call is go.
- `acme-held/`: Invoice Chaser 1.0. CI has a failing check, a critical bug is open, and the tone eval is below its threshold, so the call is no-go.
- Saved `gh` output for the held release, for the GitHub reader tests, is in `evals/fixtures/gh/` in the repository.
